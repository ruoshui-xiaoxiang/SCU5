# SCU6.0 发布说明 · 太极熵税对子版

> **版本**：SCU6.0
> **代号**：太极熵税对子版
> **上一版本**：SCU5.0-beta
> **发布日期**：2026-08-13

---

## 一、版本概述

SCU6.0 在 SCU5.0 基础上引入**太极熵税模型**与**单元对生命周期生态**，将熵税从"资源配额"升级为"对子生命力"，实现阴阳两极的权衡限定。对子状态首次真正干预对话输出：偏度极端时强制阴阳双签校验，是真正的能力互补而非单模型自我调整。

### 核心突破

| 维度 | SCU5.0 | SCU6.0 |
|------|--------|--------|
| 熵税定位 | 资源配额（限制运行） | 对子生命力（限制边界） |
| 偏度干预 | 无 | 阴阳双签回调 |
| 对子协作 | 单模型自调整 | 分工协作生态 |
| 死亡机制 | 余额耗尽即拒 | 回调失败自然死亡 + 经验回收 |
| 扣税方式 | 工具执行扣税（方案A） | 意图扣税（方案B） |

## 二、太极熵税模型

### 2.1 设计哲学

熵税不再是"能力运行的限制"，而是"能力边界的限制"。将熵税与标准计算单元的状态绑定，作为阴阳两极的权衡限定：

- **阴消阳长守恒**：阴势能消耗转化为阳势能，反之亦然
- **偏度度量**：`bias = (E_yang - E_yin) / (E_yang + E_yin)`，取值 [-1, 1]
- **回调成本递增**：偏度越大，回调所需势能越大
- **自然死亡**：偏度极端且回调失败时，对子死亡，经验回收

### 2.2 回调成本函数

```
C(b) = k * (exp(α * |b| / (1 - |b|)) - 1)
```

- 当 `b → 1` 时，`C(b) → ∞`，实现"无限偏向需无限势能"的设计意图
- 参数默认值：`k = 1.0`，`α = 1.5`

### 2.3 意图扣税（方案B）

在 `cognition.process()` 开头调用 `_charge_by_intent()`，每轮对话扣税1次，按意图分类扣税：

| 意图类型 | 极性 | 扣税来源 |
|----------|------|----------|
| analytical | 阳 | 阳势能池 |
| knowledge_query | 阴 | 阴势能池 |
| creative | 阳 | 阳势能池 |
| conversational | 中 | 阴阳各半 |
| time / weather | 中 | 阴阳各半 |

**性能优化**：
- 延迟持久化：扣税仅更新内存，异步落盘
- 回调异步化：双签在后台线程执行，不阻塞主对话
- 对子查找缓存：LRU缓存避免重复查找

## 三、单元对生命周期生态

### 3.1 单元对（UnitPair）

阴阳两单元组成的活体生命，具有完整生命周期：

```
诞生 → 运行 → 偏度累积 → 自判回调 → 续命/死亡 → 经验回收 → 重生
```

**核心属性**：
- `pair_id`：对子唯一标识
- `tracker`：偏度追踪器（PolarizationTracker）
- `is_alive`：是否存活
- `last_callback_response`：最近一次回调双签回复
- `specialty`：专长领域

**稳定性阈值**：
- `gamma_yin ≥ 0.75`：阴单元稳定度阈值
- `gamma_yang ≥ 0.65`：阳单元稳定度阈值
- 两单元均达标时，对子可续命

### 3.2 对子协作生态（PairEcosystem）

管理多对子的分工协作：

- **对子池管理**：维护活跃对子池
- **分工协作**：按专长分配任务
- **偏度互补**：偏阳对子与偏阴对子协同
- **协同融合**：多对子融合输出
- **势能借贷**：对子间势能借贷平衡
- **经验传承**：死亡对子经验注入新对子

### 3.3 回调双签（方案2）

当对子偏度超过阈值（`|bias| ≥ 0.7`）时，触发阴阳双签：

1. 检测偏度超阈值
2. 直接执行阴阳双签作为中和融合
3. 双签结果作为回复输出
4. 扣除回调成本势能
5. 清除回调回复，避免复用

**关键修复**：`last_callback_response` 使用后立即清除，防止后续对话复用旧回复。

## 四、隔离沙箱（SCU5 继承）

### 4.1 安全措施

- **AST语法树预检**：拦截危险属性访问（`__class__`）、危险函数调用（`eval`/`exec`）、`import`语句
- **内置函数白名单**：仅允许安全内置函数
- **超时限制**：默认5秒，超时通过`ctypes`注入`KeyboardInterrupt`强制中断
- **目录隔离**：限制文件操作范围

### 4.2 模块白名单

允许导入的模块：`math`、`json`、`re`、`datetime`、`random`、`string`、`itertools`、`functools`、`collections`、`statistics`

### 4.3 错误信息透传

修复 `cognition.py` 中 `code_run` 结果只读取 `output` 字段的问题，现在同时拼接 `output` 和 `error` 信息返回给用户。

## 六、API 接口

### 6.1 单元对生态系统

| 端点 | 方法 | 说明 |
|------|------|------|
| `/upair/status` | GET | 获取对子生态系统状态 |
| `/upair/pairs` | GET | 列出所有对子 |

## 九、已知限制

1. 对子生态系统默认启用，可通过环境变量 `SCU5_PAIR_ENABLED=0` 关闭
2. 回调双签依赖阴阳两单元均可用，单元不可用时降级为单签
3. 沙箱超时后线程通过 `ctypes` 注入中断，极少数情况下可能残留
4. 意图扣税依赖意图识别准确性，误识别会导致扣税来源错误
